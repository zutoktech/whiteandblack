# White & Black — Website

Website for **White & Black**, creative agency and print partner in Trichy, Tamil Nadu (since 2006).

## Pages
- `index.html` — homepage with animated product showcase
- Product pages: packaging, business cards, brochures, hoardings, logo design, social media (one folder each)

## Files
- `style.css`, `script.js` — homepage styles and animations (GSAP, ScrollTrigger, Lenis from CDN)
- `product.css`, `product.js` — product page styles and script
- `sitemap.xml`, `robots.txt`, `llms.txt` — search engine files
- `images/` — site images

## Run locally
Open `index.html` through any static server, for example:

```bash
python -m http.server 5500
```
